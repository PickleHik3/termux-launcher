Termux Launcher help clips

Muted, looping strips per help topic. Open this file next to the media (art/help-guide/). Videos start paused; press play. See README.md for embedding.

places covered

Swipe along the status bar to Widgets and back to Terminal.

corners covered

Hold the top-left pane corner, tap ?, the help overlay opens; Back closes it.

palette covered

Swipe up on the space bar, type "split", results appear.

status partial

Only the swipe-along-the-bar half is shown. The drag-down-for-the-clock expansion never fired from injected touches on Waydroid; not captured.

stats covered

Tap the weather glyph; its detail card drops from the bar; tap away closes it.

dock covered

Pull the dock down, the drawer opens; Back closes it.

az partial

Slide along the A-Z row: letters react under the finger. The drag-up-to-an-app half is not shown (it would launch an app).

organize_apps covered

Drawer, long-press Clock, Pin, Back: Clock joins the dock. Reorder and folders are not shown.

widget covered

Long-press an empty cell on the Widgets place, Add widget opens the picker.

pages covered

Long-press, Add page, then swipe sideways between pages (page dots change).

copy_paste covered

Long-press text, Copy, long-press an empty spot, Paste.

mouse_mode covered

Tap Mouse twice; the mouse mark appears and leaves the status bar.

text_size covered

Two-finger pinch out and back in inside the pane.

find_text covered

Palette, "search", Search scrollback, type "tlstore": matches highlight; Back closes the strip.

hierarchy covered

Tap the session badge; the Sessions panel opens.

keyboard covered

Tap Keyboard on the extra keys row: hide, then show.

keys covered

Tap Mouse twice, then swipe up on Split for its second action (new window).

keyboard_layouts covered

Swipe up on Keyboard: docked, floating, split, docked.

shortcuts covered

Tap Ctrl then Alt: the keys show their shortcut labels; tap again to release.

space covered

Swipe up-left and up-right on the space bar: the selected window tab changes.

settings covered

Swipe the Alt key toward its cog; Settings opens.

panes covered

Split, drag the divider (hold a corner on it first), tap a pane, hold its corner and Close.

move_panes blocked

Dragging the Move button onto the neighbour retiled the pane (Automatic tiling on) and left one pane visible instead of a swap; no usable take.

no clip

float_pane covered

Palette, Float / dock pane: the pane floats; the same action docks it again.

windows covered

Tap a tab, tap again for x, close, tap + for a new window.

workspaces covered

Palette, Save workspace: the naming dialog opens.

layout_editor covered

Corner tab, grid button, Landscape/Portrait, Done.

appearance_editor covered

Corner tab, sliders button, raise the card, move Opacity and back, Done.

base_values covered

On the Terminal surface, move Opacity: it goes independent; tap the Follow Base mark to hand it back.

themes covered

Settings > Look, scrolled.

setup blocked

The setup notice only shows while packages are missing; this Waydroid has X11 installed, so it cannot be shown without uninstalling packages.

no clip

start covered

Tap Start display; separately, corner tab > Power > Stop.

display_apps blocked

No app chip appeared in the status bar for xterm on this setup, so there was nothing to tap.

no clip

scale covered

Corner tab out, drag the scale rail thumb down and back.

touchpad partial

Mouse on, one-finger move and tap, Mouse off. Two- and three-finger gestures not shown.

display_keys covered

Tap the Linux window, type on the in-app keyboard (goes to xterm), tap Terminal to come back.
