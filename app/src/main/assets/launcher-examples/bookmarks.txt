# ~/.termux/bookmarks.txt
#
# Bookmarks for Termux Launcher's command palette.
#
# Open the palette, type ? (or "go "), and these appear alongside the pages you
# have opened before. Selecting one opens it in your default browser.
#
# This file ships with the app and every entry below is commented out, so as it
# stands it adds nothing. Uncomment a line to make it real, or write your own.
#
# A pristine copy of this file is refreshed at every app start in:
#
#     ~/.termux/launcher/examples/bookmarks.txt
#
# Your edits here are never overwritten by an app update. There is nothing to
# reload: the palette re-reads this file whenever it opens.
#
# Syntax
#   <name><TAB><address>          # a tab, or two or more spaces, separates them
#   <address>                     # named after its host
#
# Only http and https addresses are kept. A line missing its address is skipped
# and the rest of the file still loads. `#` starts a comment.
#
# Limits: 128 KiB, 2048 lines, 512 bookmarks.
#
# A bookmark can also be bound to a key chord in
# ~/.termux/termux-launcher-bindings.conf:
#
#     map --label "Nix packages" ctrl+alt+n web.open https://search.nixos.org/packages
