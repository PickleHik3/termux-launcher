# Changelog — v0.2.35-nix

The Nix edition (`com.termux.launcher.nix`) ships the same launcher as the main
release. Everything in the main [v0.2.35 changelog](release-notes-v0.2.35.md)
applies here too; this file lists only what is exclusive to this edition.

## New

- The bootstrap now arrives with the environment already set up, so the first
  launch lands in a configured shell instead of asking you to run setup.
