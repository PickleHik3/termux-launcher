# Changelog — v0.2.37-vaj+hotfix1

The VAJ edition of the [v0.2.37+hotfix1 release](https://github.com/PickleHik3/termux-launcher/releases/tag/v0.2.37%2Bhotfix1) — the same hotfix, plus the edition notes below.

## Edition notes

- **This is the demo edition, and the least recommended one to install.** Its
  packages come from my own apt repository, which is updated sometimes, with no
  promises. For a repository you can rely on, install the Nix or the Termux
  edition.
- It is no longer frozen to security fixes: it now gets every release the other
  editions get.
- This edition ships for 64-bit ARM devices (`arm64-v8a`) only.
