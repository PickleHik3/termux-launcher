# Changelog — v0.2.35-a-nix

The Nix edition of the [v0.2.35-a fix release](https://github.com/PickleHik3/termux-launcher/releases/tag/v0.2.35-a) — same fixes, nothing edition-exclusive.

## Fixes

- The Style entry is back in the terminal long-press menu when TLNix:Styling
  is installed — this edition was the one missing it (#13).
- Removed the tinted square edges behind the rounded corners of the CPU and
  weather cards (#13).
- The Lazy Mode toggle now actually saves, and applies without restarting the
  app.
