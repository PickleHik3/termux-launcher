# Studio: an AGSL wallpaper maker

Status: agreed with the developer 2026-11-07 (grilling session); not built. Replaces the Live
scenes picker. Background research:
`project-docs/reference/launcher/ai-wallpaper-generators-research-2026-11-07.md` (Pixel AI
wallpapers and Nothing Wallpaper Studio).

## Revision 2026-11-08 (after the first Bloom review)

The developer found no real variety in the Bloom lab and too many words (nine). Changed:

- **Three words only: Subject · Material · Colour.** "A [glass] [Ripples] in [Glacier]."
  Subjects are the six families: Bloom, Pebbles, Silk, Ripples (was Caustics), Horizon, Cosmos.
  Materials: Glass, Frosted, Ink, Glow, Clay. Colours: the 12 palettes (Dusk, Ember, Glacier,
  Moss, Coral, Orchid, Graphite, Saffron, Tide, Rose, Slate, Meadow).
- **The seed decides everything else**: tempo, mood, placement, texture and each subject's own
  details (Bloom's form, petal count, layers; Pebbles' shapes and count; and so on). Shuffle and
  each Variations tile must therefore look clearly different.
- Shuffle changes the unlocked words among the three, plus the seed.
- **Lab order**: all six subjects first, at rough quality, so the range of the set is judged at
  once; polish follows for the ones the developer keeps. This replaces "family by family".

Where the tables below list shared slots (mood, tempo, placement, texture) or a family's own
words, read them as seed-driven ranges, not words the user picks.

## What it is

Pixel and Nothing let the user build a wallpaper from a closed set of words and generate an image
with a model. Studio does the same with hand-written AGSL: a **recipe** is a family, one word per
slot and a seed. Every recipe renders instantly, offline, live, and at the cost of a normal scene.

The five current Live scenes (Aurora, Contour waves, Nebula, Fractal bloom, Particles) were a
trial. Only the developer has used them, so nothing migrates. Studio's families are new, designed so
that combinations stay far apart. Taste hints from the trial: Fractal bloom's natural, flower-like
motion and glass petals set the bar; Particles and Nebula drift came second.

## Decisions

| Decision | Choice |
|---|---|
| What a recipe is | Family + words + seed. Hand-written shader families; no AI-written shaders |
| Picker | A tappable sentence, Pixel style. Every underlined word opens its list |
| Output | Always live. No freeze-to-still |
| Colours | The recipe's palette sets the launcher scheme |
| Placement | Replaces the Live scenes picker; the current scenes are removed |
| Local AI | Not in v1. Later: Gemma fills the sentence from typed or spoken text, choosing only from the lists |
| Saving | The last 12 creations are kept automatically; starred ones stay as favourites |
| Daily shuffle | Not now |
| Families in v1 | Bloom, Pebbles, Silk, Caustics, Horizon, Cosmos |
| Material | A shared word across families, with a compatibility table |
| Readability | No limit. Loud, high-contrast results are allowed |
| Editor | Live full-screen preview behind a sentence sheet; Shuffle, Variations (4 seed tiles), Set |
| Shuffle | Changes every unlocked word, family included, plus the seed. Long-press a word to lock it |
| Frame rate | Stays a separate battery setting (15/30/60 Hz), not part of a recipe |
| Light and dark | Each palette has a light and a dark version and follows the system |
| Horizon sky | Follows the real clock. Chrome colours step four times a day (dawn, day, dusk, night) |
| Name | **Studio** (chosen knowing Nothing ships "Wallpaper Studio") |
| Route | Desktop shader lab first, reviewed family by family starting with Bloom, then ported |

## Recipe

```
recipe = { family, words: { slot: word, ... }, seed }
```

A recipe is a few bytes, stored as a short string. The sentence is generated from the recipe, and
each word maps to uniform values through a table owned by its family. One pure model
(`StudioRecipe`, with tests) owns the word lists, the compatibility rules, shuffle-with-locks and
the word-to-uniform mapping. The lab, the editor and the renderer all read it.

### Shared slots

| Slot | Words (draft; final lists come out of the lab) | Drives |
|---|---|---|
| Palette | about 12 named palettes, e.g. Dusk, Ember, Glacier, Moss, Ink, Coral | colours + scheme seed, light and dark versions |
| Material | glass, frosted, ink, glow, clay | how surfaces shade: refraction-like edges, diffusion, flat ink, emission, matte |
| Mood | quiet, balanced, vivid | contrast and brightness |
| Tempo | barely moving, slow, lively | speed |
| Placement | centre, low, corner, scattered | where the focal form sits |
| Texture | clean, fine grain, film | grain and finish |

### Families

Each family has its own structure and its own kind of motion. Recipes differ mainly by family,
then by palette and material, which gives about 300 looks that are clearly different at a glance.

| Family | Look | Motion | Own words |
|---|---|---|---|
| Bloom | One organic form: flower, anemone, star, spiral shell | Breathes open and closed; outer petals lag the inner ones | form, petal count (3–12), layers (1–4) |
| Pebbles | 5–20 soft shapes (rounded squares, pills, cookie shapes, stones) at depths, with soft shadows | Slow drift with depth parallax; glass ones tint what's behind | shape set, how many, depth (flat or deep) |
| Silk | One draped sheet lit from the side | Folds slowly as if in a breeze; the sheen slides | fold (soft, deep, crumpled), light direction |
| Ripples | Light from rippling water on sand, tile or darkness | The light network shifts like a pool floor | depth (shallow pool or deep sea), ripple size, floor |
| Horizon | Layered silhouettes (dunes, peaks, sea, hills) under a sky | Slow parallax and haze; the sky follows the clock | land, sky object (sun, moon, none) |
| Cosmos | Gas clouds and stars | Clouds drift, stars twinkle | cloud shape (wisp, spiral, ring), how many stars |

The material compatibility table (for example, no glow Silk) is settled per family in the lab.
Shuffle only picks allowed combinations.

### Horizon and the clock

The sky interpolates continuously from the time of day. The scheme seed steps at four points
(dawn, day, dusk, night), so chrome re-tints rarely. The palette sets the land and the tint.

## Constraints

- AGSL limits (from `agsl-capabilities-research-2026-11-05.md`): no textures, no preprocessor,
  loops with constant bounds only, float and int uniforms only. Every family is a stateless
  function of position, time, seed and uniforms.
- Performance: read `docs/agents/performance.md` before porting. Caustics, Silk and Cosmos are the
  heaviest. Each family must hold the current ambient frame budget on pong at 30 Hz, and keep the
  existing holds (battery saver, thermal, hidden layer) that `SceneController` and
  `SceneFramePolicy` apply today.
- The scheme seed comes from the palette, not from measuring rendered pixels.
- Variations tiles are still renders (`SceneStill`) taken while the sheet is open, never four live
  scenes.

## Shader lab

- Shader sources live once, as `.agsl` files the app loads. The lab loads the same files, so a
  port is the files themselves, never a copy.
- The lab is a static page run on CanvasKit (Skia's SkSL runtime effects, the language AGSL is). It
  has the sentence controls, Shuffle, seed, and phone-shaped frames at pong's aspect. It is served
  from `~/reports/studio-lab/` over Tailscale.
- Review is family by family, starting with Bloom. The developer approves or redirects each one
  before the next starts. Palettes are tuned in the lab alongside the families.
- The desktop is not pong. Every approved family gets a pong pass for speed and look before it
  ships.

## Build order

1. Lab shell + Bloom → review.
2. Pebbles, Silk, Caustics, Horizon, Cosmos, one at a time → review each.
3. `StudioRecipe` model with tests (words, compatibility, shuffle-with-locks, mapping).
4. Renderer: load family `.agsl` sources and feed uniforms from the recipe; palette → scheme seed.
5. Editor: sentence sheet, word lists, locks, Shuffle, Variations, Set; recent + favourites.
6. Remove the Live scenes picker and the trial scenes.
7. Horizon clock and the four-step scheme.
8. Pong pass per family; owed checks to `project-docs/device-checks.md`.
