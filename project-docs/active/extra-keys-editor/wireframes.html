Shared measurement / behavior rules

LayoutLogical 393 × 812 dp reference viewport; 24 dp status strip; 56 dp app bar; 24 dp gesture inset. All mockup coordinates use CSS px as dp.
Tap targetsPrefer 48 × 48 dp or larger interactive hit areas. Key caps are 48 dp high; use at least 48 dp hit targets for other controls too. Gaps 7–8 dp.
Editing / persistenceEditing happens on a draft. Done closes a sheet and updates that draft; Save changes commits globally; Cancel discards the draft; removal offers Undo.
ReorderingLong-press then drag keys; reorder rows/pages using handles or menu actions. Key editor also provides accessible Move left / right buttons.
OverflowRow representation should match real Termux overflow/wrapping behavior. Editor keys scroll horizontally while Add stays pinned; runtime overflow or wrapping must be verified against Termux.
ActionsTerminal keys, app controls and custom actions share one picker but are grouped distinctly. Swipe-up is optional; labels can differ from actions.
