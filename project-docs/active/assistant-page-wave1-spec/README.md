# Assistant page, wave 1 build spec (2026-11-05)

Text extracted from the OpenDesign project "Assistant page spec sheets" (rendered copy:
https://amal-build.taild9c5dc.ts.net/reports/assistant-specs-2026-11-05/). Decisions: ADR 0022.
The developer approved the renders on 2026-11-06, including these values OpenDesign chose itself:
top bar 56, composer 56 growing to 6 lines, your-message corners 20/20/6/20, code 13/20,
"Working on it", "Chat deleted" + Undo, "Assistant page removed. Your chats are kept." + Undo,
the Chats list sliding over the chat inside the page, no mobile-data prompt before a download.

Known deviation: sheet 06.2 invents an "Add a page" sheet from Home actions. The launcher adds
kinds from the Edit pages overview pills; the Assistant pill there is the real entry.
Rows marked "existing" or "stand-in" (On-device AI settings rows, Add a page's Home row) are
placeholders; keep the real rows.
