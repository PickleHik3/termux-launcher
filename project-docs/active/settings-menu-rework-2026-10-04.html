Shared controls have one home.

App-wide vibration, idle activity and Recents behavior currently appear in unrelated places. The rework provides a canonical destination with shortcuts from the places people expect to find them.

Scope and review boundary

Stack: Android Material preferences and existing live editors. The wireframes reuse the app’s muted purple/neutral palette, readable list rows and full-width controls. They are HTML design sketches, not a request to replace the native stack.

Evidence: 50 original captures from pong’s installed version 1.0.0; source inventory at HEAD 0bcfbb7a4. That source is newer than the capture-session baseline. The AI captures were black, so those screens use source evidence only. Existing inner editors are explicitly marked as handoffs rather than falsely presented as reviewed redesigns.

Documents: AGENTS.md’s short-title/one-sentence product-copy guidance, its custom-preference layout constraint and its requirement for status-control previews. The better-interface coordinator and its review-format.md were loaded.

What the implementation must preserve

  • Existing preference keys and stored values, including portrait/landscape sizing. Hidden dependent controls do not lose values.
  • Search results and direct settings routes. Back returns through the actual entry path, including Appearance and shared pages.
  • Permission purpose, clipboard/program access, sensitive logging, model requirements, LAN authentication/expiry and existing confirmations.
  • Fonts, icon packs, custom XML layouts, extra keys, speech/cleanup models, Linux app setup, privilege backends and AI tuning remain available.

Artifact checks

The inline script parsed, all 57 navigation destinations and screenshot references resolved, and desktop/narrow light previews rendered. Headless force-dark-mode did not change the preview theme; dark tokens are provided but a rendered dark check is not claimed.

Checks required before shipping

Verify the implemented screens at 360/411 dp, 320 dp narrow width, large text, light/dark themes, TalkBack, hardware-keyboard navigation and RTL. Exercise missing permissions/models, invalid files, wallpaper loading/errors and destructive-action cancellation. The wireframes do not count as those device checks.

All screenshots are unmodified originals. UI selections and state sketches are examples. The report is local; the original screenshot archive remains under work-logs/pong-settings-review-2026-10-04.tar.gz.
