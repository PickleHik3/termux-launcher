## Edition notes

- **This is the demo edition, and the least recommended one to install.** Its
  packages come from my own apt repository, which is updated sometimes, with no
  promises. For a repository you can rely on, install the Nix or the Termux
  edition.
- This edition ships for 64-bit ARM devices (`arm64-v8a`) only.
