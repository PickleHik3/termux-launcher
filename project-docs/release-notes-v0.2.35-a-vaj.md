# Changelog — v0.2.35-a-vaj

The VAJ edition (`io.vaj.tl`) is **deprecated** and normally receives security
fixes only; this small fix release rides along to keep the editions in step.
Same fixes as the [v0.2.35-a release](https://github.com/PickleHik3/termux-launcher/releases/tag/v0.2.35-a), nothing edition-exclusive.

## Fixes

- Removed the tinted square edges behind the rounded corners of the CPU and
  weather cards (#13).
- The Lazy Mode toggle now actually saves, and applies without restarting the
  app.
